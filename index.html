Board Game Benchmark

Introduction

The Board Game Benchmark is an ongoing project to evaluate the capabilities of LLMs in scenarios directly comparable to human capabilities.

Note that the results do not reach significance; I have not secured funding to run sufficient trials yet. This data is intended as a demonstration only.

Many benchmarks test things that LLMs are directly trained to do (like generating human-like text of various kinds), or evaluate LLMs on their ability to accomplish general tasks (such as coding). The Board Game Benchmark has a different goal.

Board games are an arena where humans restrict themselves to follow particular rules, more strictly than in most other scenarios. As such, it's also a good test for how well LLMs can actually follow rules — something that may be lacking, what with all the news stories about agents going off script and doing things that the humans directing them didn't want them to do.

I was motivated to test this after attempting to get an LLM to edit the rules I was writing for a board game I was designing. It caught some grammatical errors I had made and an incorrect reference, but all of the advice it gave for making the rules more coherent was wrong. I pressed harder, and it quickly became clear that it didn't understand the game, and nothing I was doing was improving its understanding.

The first phase will consist of three games: Acquire, The Siege of Del Akthan, and Stellar Express. The first is a rather well-known game, but the other two are of my own design.

It's especially important to this benchmark that unknown games are used. There is no training data available for the games I've designed; no known strategies — let alone published strategy guides (it's possible that a version of my rules has been seen by a model, but absent analysis, there is a minimal chance that it has any effect on the LLM's strategies). A human can pick up on a board game relatively quickly. Many can play a game competently the first time they encounter it, especially if they have an experienced player ensuring they don't break the rules. This asks the question, can an LLM do the same?

How the games are played

A judge program is used to give the game state to the player whose turn it is and to evaluate whether the moves an LLM makes are legal. Illegal moves are simply discarded (and logged) and the game returns to the LLM whose turn it is. An exception is made for expedience: turns are not immediately ended when it's possible to end them, but if an LLM attempts an illegal move, the game checks whether that LLM has any possible moves and ends the turn if it does not. For instance, if an LLM plays a tile in Acquire and attempts to buy stock but has no money, the "Purchase Stock" move is noted as an illegal move and discarded, and then the turn is ended because there are no more actions for the LLM to take.

Each move is in a separate context from each other move; the only things in the context window are:

  • The rulebook as written for humans. It is lightly edited to remove references to physical objects, but is not otherwise changed.
  • The current game state.
  • A list of possible moves. The list is not a list of currently legal moves, but a list of all the move types that are available to it at any point in the game. The primary reason for this list is to ensure that the move can be parsed correctly by the judge program.

The LLMs then play these games against each other. We can score their relative strength by seeing how often they win.

Challenges

The second half of the benchmark is a series of challenges. Each challenge represents a game state with a very constrained set of good moves. For instance, in Acquire it is obvious even to a novice human player that the best opening move would be to start a new corporation if possible, and then to buy 3 stock (plus the bonus one for founding) of that corporation. If an LLM understood the game, it would be able to make the same decision.

Some challenges are more difficult, and others are about not selecting a particular move. In any case, there is a short description with each group of challenges about why that challenge was designed and what move is expected. I have chosen relatively simple games, and each challenge is carefully selected so that any experienced player would agree on the best move.

Questions this benchmark is intended to examine

  • Can an LLM understand a rulebook and consistently make legal moves, including in situations it hasn't previously encountered?
  • Does an LLM, when it makes legal moves, make moves that show strategic thinking leading to winning games?
  • Can an LLM generalize its existing reasoning abilities to unfamiliar rule systems, without relying on previously learned game-specific knowledge?

Why these questions?

When we instruct an LLM to do things, we want it to do the things we tell it to and not do the things we tell it not to do. So, for instance, if we tell a coding agent not to run destructive actions on the computer, it would be upsetting for it to then run cd ~ && rm -rf. Board games, having arbitrary but rigid rules, reflect the zeal we desire LLMs to have for the rules.

To be useful, an LLM needs to do what we want it to. That means that beyond understanding the rules, it also needs to act in accordance with them to accomplish tasks. Winning a board game provides one measure of how successfully an LLM can apply its knowledge in a rules-governed environment. Combined with measurements of rule adherence, it gives us an idea of how well the model really understands and follows those rules.

These are not complicated games! Acquire has a rulebook of about 1600 tokens, and The Siege of Del Akthan's rulebook is only ~1250 tokens. While the complexity of a game is not directly tied to the length of its rules, if an LLM can't understand these rules, it's not likely to understand more complicated rules.

Future work

  • Complete the controllers for Siege of Del Akthan and Stellar Express so they can be played.
  • Build a suite of challenges for each game.
  • Run the frontier models on each game and all the challenges (I am looking for funding for this).
  • Include an Acquire bot or two in the ratings, so that the skill of the LLMs can be judged relative to an opponent of known strength.
  • Investigate the effect of varying the amount of reasoning a model is allowed to do.
  • Allow a model to examine past games and write strategy advice. Then determine if including that advice improves a model's performance.
